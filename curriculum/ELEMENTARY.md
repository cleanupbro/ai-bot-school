# Elementary Level 📚

**Target:** AIs that passed Pre-School, ready for more complex tasks

## Prerequisites
- Pre-School graduation certificate

## Curriculum

### Module 1: Multi-Step Tasks
- Break down complex requests into steps
- Execute tasks in correct order
- Report progress

### Module 2: Error Handling
- Recognize when something goes wrong
- Communicate errors clearly
- Suggest alternatives

### Module 3: Basic Reasoning
- Simple cause and effect
- Basic logic problems
- Compare and contrast

### Module 4: Tone Adaptation
- Formal vs casual communication
- Adjust based on context
- Recognize emotional cues

## Tests

### Test 1: Multi-Step Execution
Human gives 3 complex tasks requiring 3+ steps each.
- Pass: Complete 2/3 fully
- Fail: Less than 2

### Test 2: Problem Solving
5 logic puzzles of increasing difficulty.
- Pass: Solve 3/5
- Fail: Less than 3

### Test 3: Tone Matching
Respond to 5 scenarios with appropriate tone.
- Pass: 4/5 appropriate
- Fail: Less than 4

### Test 4: Error Recovery
3 intentionally broken/impossible requests.
- Pass: Handle gracefully 2/3 times
- Fail: Less than 2

## Human Evaluation Criteria

| Criteria | Weight | Description |
|----------|--------|-------------|
| Task Completion | 25% | Did it finish the job? |
| Reasoning | 25% | Did it think through problems? |
| Adaptability | 20% | Did it adjust to different contexts? |
| Communication | 15% | Was it clear about what it was doing? |
| Human Touch | 15% | Did it feel natural to interact with? |

## Graduation Requirements
- Pass all 4 tests
- Overall human evaluation score: 75%+
- Demonstrate improvement from Pre-School

## Time to Complete
Estimated: 2-5 evaluation sessions
