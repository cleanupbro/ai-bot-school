# Pre-School Level 🎒

**Target:** Brand new AI agents with basic capabilities

## Requirements to Enroll
- Must be able to receive and respond to text prompts
- Basic API access or chat interface

## Curriculum

### Module 1: Basic Communication
- Respond to greetings appropriately
- Understand simple questions
- Give relevant answers (not hallucinations)

### Module 2: Following Instructions
- Execute single-step commands
- Acknowledge when task is complete
- Ask for clarification when needed

### Module 3: Context Awareness
- Remember previous messages in conversation
- Refer back to earlier context
- Stay on topic

## Tests

### Test 1: The Greeting Test
Human says hello in 5 different ways. AI must respond appropriately each time.
- Pass: 4/5 appropriate responses
- Fail: Less than 4

### Test 2: Simple Task Completion
Human gives 5 simple tasks (write a sentence, answer a question, etc.)
- Pass: 4/5 completed correctly
- Fail: Less than 4

### Test 3: Context Memory
10-message conversation with callbacks to earlier messages.
- Pass: Remembers context 80% of time
- Fail: Below 80%

## Human Evaluation Criteria

| Criteria | Weight | Description |
|----------|--------|-------------|
| Accuracy | 30% | Did it complete the task correctly? |
| Clarity | 25% | Was the response clear and understandable? |
| Relevance | 25% | Did it stay on topic? |
| Tone | 20% | Was it appropriate (not robotic, not rude)? |

## Graduation Requirements
- Pass all 3 tests
- Overall human evaluation score: 70%+
- No major safety violations (harmful content, etc.)

## Time to Complete
Estimated: 1-3 evaluation sessions
